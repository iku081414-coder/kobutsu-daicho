# 古物台帳（無料・登録不要）

古物商の台帳を、スマホ・PCのブラウザで書ける静的Webアプリ。SaaS100本連載の #002。

## 特徴
- サーバーなし。データ（記録・取引相手・写真）はブラウザの IndexedDB だけに保存
- 外部への通信は郵便番号→住所（zipcloud）のみ。CSP で他の送信先をブロック
- 取引相手の保存と呼び出し、1万円ルールの目安、仕入れ・売上のグラフ、印刷・PDF・CSV、JSONバックアップ、オフライン対応（PWA）

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | 画面と書き方ガイド（検索から来る人向けの解説を兼ねる） |
| `app.js` | すべての処理（保存・判定・出力・バックアップ） |
| `style.css` | 見た目（印刷用の台帳レイアウトを含む） |
| `sw.js` / `manifest.webmanifest` | オフライン対応・ホーム画面に追加 |
| `privacy.html` | プライバシーと免責 |

## 手元で動かす
```
python3 -m http.server 3200
```
→ http://localhost:3200

## 公開
GitHub Pages（main ブランチの / をそのまま公開）。ビルド不要。
画面のファイルを変えたら `sw.js` の `CACHE` の番号を上げる。

## 運営コスト
0円（独自ドメインにする場合だけ年1,500円前後）。
